# Ficha do Tripa Seca — Rainha Rubra

Ficha de personagem editável para a campanha **Rainha Rubra**, feita para usar no celular.

- Abra o link no navegador e toque em qualquer campo para editar.
- Tudo é salvo automaticamente no aparelho (localStorage).
- **Exportar cópia** baixa um `.json` com a ficha; **Importar cópia** restaura em outro aparelho.
- **Restaurar Tripa Seca** volta para a ficha original; **Ficha em branco** limpa tudo para outro personagem.
- No celular, use "Adicionar à tela inicial" para abrir como app.

Site estático (HTML + CSS + JS, sem build). Para mudar os dados originais do Tripa Seca, edite `TRIPA_SECA` em `app.js`.
